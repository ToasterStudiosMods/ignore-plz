1 · Quick check — built-in 64-bit demo

Runs a tiny El Torito ISO (embedded in this file) that boots a 64-bit long-mode test kernel through the same CD-ROM → BIOS → bootloader path a Bliss ISO takes. No files needed — proves the emulator works on your machine in ~20 seconds.

expect: “X86-64 LONG MODE ACTIVE”

2 · Bliss OS x86_64 ISO

Get Bliss OS from SourceForge · blissos-x86 (or your favourite mirror). Pick the x86_64 .iso build. The ISO is supplied at runtime because a ~2 GB image cannot live inside a single HTML file. voyager-x86 = Bliss OS 18 / Android 15.

4096 MB total — pick an ISO to compute

Wasm linear memory tops out at 4 GB and must hold guest RAM + ISO + optional disk + emulator. The harness auto-clamps guest RAM to fit. For a full Bliss OS install (needs ISO + disk), keep RAM low or boot a smaller ISO. Live-booting the ISO (install-later) is the default and always fits. Recommended host RAM: 16 GB+.
